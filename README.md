# 🏁 부릉부릉 영어 그랑프리

보드게임 '히트'의 자동차 경주 규칙에 6학년 영어 **10·11·12단원** 문제를 넣은 실시간 모둠 게임이에요.

- 학생 화면: `https://내주소/`  (QR이나 `?code=1234` 주소로 들어오면 방 코드가 자동으로 들어가요)
- 교사 화면: `https://내주소/teacher.html` (교사 비밀번호가 필요해요)

## 1. Render에 올리기 (다른 게임과 같은 방법)
1. 이 폴더를 GitHub 저장소에 올려요. (`node_modules`, `data` 폴더는 올리지 않아도 돼요)
2. Render → New → Web Service → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포가 끝나면 나온 주소 뒤에 `/teacher.html`을 붙여 교사 화면을 열어요.

> 무료 Render는 한동안 안 쓰면 잠들어서 첫 접속이 30초~1분 걸려요. 수업 전에 교사 화면을 한 번 열어 깨워 두세요.
> 서버가 다시 시작되면 진행 중인 경기와 기록이 사라질 수 있어요. 수업이 끝나면 **결과 보기 → 결과 엑셀로 저장**을 눌러 두세요.

내 컴퓨터에서 시험해 보기: `npm install` → `npm start` → http://localhost:3000

## 2. 수업 진행 순서
1. 교사 화면에서 **새 수업 만들기**를 눌러요. 방 코드 4자리와 QR이 나와요.
2. **게임 설정**에서 단원을 골라요.
   - 한 단원만 고르면 그 단원 문제만 나와요.
   - 여러 단원을 고르면 트랙 구역마다 단원이 달라져서 섞여 나와요. (🍝 푸드 스트리트 10단원 · 🏯 한옥 마을 11단원 · 🌏 그린 어스 로드 12단원)
3. 학생은 이름, 방 코드, 자동차 색을 고르고 **출발!**을 눌러요.
4. **자동 배정은 처음부터 켜져 있어요.**
   - 대기실에 3명 이상 모이면 3~5명씩 방이 만들어지고 5초 뒤 출발해요.
   - 경기가 끝나면 25초 뒤 대기실로 돌아가 새 방에 다시 배정돼요.
   - 바로 전 경기에 같은 방이었던 친구는 새 방에 3명 이상 모이지 않아요. (다른 방이 끝나 친구들이 더 올 때까지 잠깐 기다려요)
   - 교사가 버튼을 누르지 않아도 계속 이어져요.
5. 필요할 때만 교사가 손대요.
   - **전체 관리**: 학생 목록에서 방을 골라 옮기기, 방별 출발·멈춤·종료·같은 팀 다시·대기실로
   - **방별 모니터링**: 트랙, 학생별 기어·엔진 열·지금 푸는 문제와 정답·고른 답, 라운드 기록
   - **일시 정지 / 전체 경기 종료**
   - 자동 배정을 끄면 **지금 배정**으로 방을 만들고 **대기 방 출발**로 시작해요.

## 3. 게임 규칙 (학생 화면 ❓에도 있어요)
- 정해진 바퀴(기본 2바퀴)를 먼저 돌면 1등이에요. 모두 **동시에** 고르고, 앞차부터 차례로 달려요.
- **기어 1~4단**: 기어 수만큼 카드를 내요. 한 번에 1단씩 바꾸고, 2단을 한꺼번에 바꾸면 엔진 열 1을 내요.
- **기어 = 문제 단계**: 1단 단어 뜻 · 2단 문장 뜻 · 3단 빈칸 채우기 · 4단 대화와 문장 순서
- **카드**: 숫자 카드 1~4 = 속도 / ❓깜짝 카드 = 정답이면 1~4 중 하나 / 🔥열 카드 = 속도 0
- ⭕ **정답**: 계획대로 달리고 부스트(열 1 → 속도 +1~4)를 쓸 수 있어요.
- ❌ **오답**: 그래도 달리지만 엔진 열 1이 빠져요. (틀린 학생도 멈추지 않게)
- 🚩 **코너**: 표지판 숫자가 제한 속도예요. 넘은 만큼 엔진 열을 내고, 모자라면 **스핀**해서 코너 앞에 멈추고 1단이 돼요.
- 💨 **슬립스트림**: 앞차 바로 뒤나 같은 칸에 서면 +2칸
- 🔧 **정비**: 1단(3장)·2단(1장)으로 달리고 정답이면 손의 열 카드가 엔진으로 돌아가요.
- 💪 **꼴찌 보너스**: 꼴찌(5명이면 2명)는 +1칸, 정비 +1
- 순위 점수: 1등 5점, 2등 3점, 3등 2점, 그 밖 1점

## 4. 문제 관리
- 기본 문제 297개 (10단원 97 · 11단원 98 · 12단원 102). 지도서 주요 단어·주요 표현으로 만들었어요.
- **문제 관리** 탭에서 단원·단계별로 보고, 문제마다 켜고 끌 수 있어요.
- 한 문제씩 직접 넣거나, **엑셀 양식 받기** → 채우기 → **엑셀/CSV 올리기**로 한꺼번에 넣어요.
  - 칸: 단원(10~12) · 단계(1~4) · 문제 · 보기1~4 · 정답번호(1~4) · 해설
- Render 무료 서버는 다시 시작하면 직접 넣은 문제가 지워질 수 있어요. 엑셀 파일을 보관해 두세요.

## 5. 결과 보기

## 7. 그래픽 (English_Grand_Prix_All_Graphics 적용)

- 트랙 배경 4종(10·11·12단원, 혼합)은 도로 가운데 선을 그림에서 직접 찾아 `public/track-data.js`에 저장했어요. 자동차는 이 선을 따라 달려요.
  - 출발선은 왼쪽 커브 가운데, 시계 방향으로 달려요.
  - 코너 3곳은 그림의 커브에 맞췄어요: 왼쪽 커브 위(제한 5)·오른쪽 커브 가운데(제한 4)·왼쪽 커브 아래(제한 3).
  - 단원을 하나만 고르면 그 단원 배경, 두 단원이면 두 단원 배경(왼쪽 = 앞 단원, 오른쪽 = 뒤 단원), 세 단원이면 혼합 배경이 나와요.
- 자동차는 색마다 주행 4·부스트 4·스핀 8프레임으로 움직여요.
- 학생 프로필 8종은 자동차 색과 짝지어 나와요(빨강 차 = 빨강 테두리 친구).

## 8. 업데이트 (11월 2일)
- **예상 도착 칸 미리 보기**: 카드를 고르면 트랙에 도착할 칸이 ★로 깜빡이고, 코너에서 엔진 열을 몇 개 쓰는지, 스핀 위험이 있는지 미리 알려 줘요.
- **영어 듣기**: 영어 미션 창의 [🔊 듣기]를 누르면 문제와 보기 속 영어를 읽어 줘요(기기의 영어 음성 사용). 결과 화면의 틀린 문제에도 듣기 버튼이 있어요.
- **틀린 문제 다시 보기**: 경기가 끝나면 내가 틀린 문제·내 답·정답·해설이 나와요. 복습할 수 있게 결과 화면을 25초 보여 줘요([대기실로]를 누르면 바로 넘어가요).
- **효과음**: 카운트다운·출발·정답/오답·부스트·스핀·결승 소리가 나요. 위쪽 🔊 버튼으로 끌 수 있어요(기기마다 기억해요).
- **시간 알림**: 라운드가 10초 남으면 시간 막대가 깜빡이고 마지막 5초는 째깍 소리가 나요. 시간이 끝나 자동으로 출발하면 알려 줘요.
- **늦게 온 학생 끼워 넣기**: 대기실에 1~2명만 20초 넘게 기다리면, 막 시작한(3라운드 이내) 경기 중 인원이 적은 방에 꼴찌 자리로 들어가요. 교사 모니터링 기록에 표시돼요.
- **연결 끊김 보호**: 한 방 학생이 모두 연결이 끊기면 그 방은 저절로 진행되지 않고 기다려요.
- **일시 정지 중 시계**: 멈춘 동안 학생 화면의 시간이 줄지 않아요.

## 10. 수업 흐름 점검 (11월 2일 오후)
`FAST=1 PORT=3999 node server.js`를 켠 뒤 `node test/audit.js`를 실행하면 아래 24가지를 자동으로 확인해요(29가지, 모두 통과).
- 자동 배정 기본 켜짐, 3~5명씩 방 나누기, 버튼 없이 출발
- 경기 끝 → 결과 화면 → 대기실 → 새 방 재배정, 전 방 친구는 한 방에 2명까지
- 새로고침해도 같은 방으로 돌아옴, 늦게 온 학생 끼워 넣기
- 자동 배정 끄기 → 지금 배정·학생 옮기기·대기 방 출발·일시 정지·경기 종료·같은 팀 다시·학생 내보내기·교사 화면 이어서 열기
- 결과 저장(학생별·경기별·틀린 문제), 두 단원 트랙 구역

추가된 것
- **2명만 남았을 때**: 대기실에 2명만 있고 다른 경기가 없으면 30초 뒤 2명이라도 출발해요. 다른 경기가 진행 중이면 그 경기가 끝나 친구들이 돌아오기를 기다리고(끼워 넣을 수 있으면 바로 끼워 넣어요), 2분이 넘으면 2명이라도 출발해요.
- **대기 시간 표시**: 교사 화면 대기실에 학생마다 기다린 시간이 나오고, 1분이 넘으면 주황색으로 바뀌어요.
- **학생 대기실 안내**: "다른 친구들의 경기가 끝나면 같이 달려요! (지금 2명)"처럼 왜 기다리는지 알려 줘요.

## 11. AI 친구와 빠른 배정 (11월 2일)
- **AI 친구 (기본 켜짐)**: 대기실에 친구가 모자라면(1~2명) 6초 뒤 AI 친구가 빈자리를 채워 3명으로 출발해요.
  - AI 이름: AI 번개·AI 터보·AI 로켓…, 화면에 🤖 표시가 붙어요.
  - AI는 엔진 열과 코너를 보고 기어·카드를 고르고, 영어 미션은 약 75%를 맞혀요. 라운드마다 4~13초 사이에 준비해요(학생이 모두 준비하면 바로).
  - 경기 중에 학생이 들어오면 가장 뒤에 있는 AI가 빠지고 학생이 그 자리를 이어받아요.
  - AI는 경기 기록에는 보이지만 학생 점수·정답률·엑셀 학생별 결과에는 들어가지 않아요.
  - [게임 설정 → 빈자리 AI 친구로 채우기]로 끌 수 있어요. 끄면 2명이라도 출발해요.
- **10초 안에 배정**: 대기실에 3명 이상 모이면 4~9초 안에 방이 정해지고, 전 방 친구와 겹칠 때 기다리는 시간도 40초 → 10초로 줄였어요.
  - 실제 시간으로 잰 결과: 혼자·2명 6초(AI와 함께), 3명·7명 4.3초에 방 배정 → 5초 카운트다운 후 출발.

## 12. 교사 비밀번호
- 교사 화면에서 **새 수업 만들기**와 **이전 수업 이어서 열기**를 하려면 교사 비밀번호를 넣어야 해요. 학생 화면에는 필요 없어요.
- 비밀번호는 선생님께 따로 알려 드렸어요. 저장소가 공개라서 코드에는 비밀번호를 그대로 쓰지 않고, 알아볼 수 없는 값(해시)만 넣어 두었어요.
- 같은 탭에서는 새로고침해도 다시 묻지 않아요. 탭을 닫거나 다른 기기에서 열면 다시 넣어요.
- 5번 틀리면 1분 동안 입력을 막아요.
- **비밀번호를 바꾸려면**: Render → 이 서비스 → Environment → `TEACHER_PASSWORD` 에 새 비밀번호를 넣고 저장하면 그 값이 쓰여요(코드는 고치지 않아도 돼요).
- 시험 프로그램(`test/`)은 `TEACHER_PW=비밀번호 node test/audit.js`처럼 비밀번호를 붙여 실행해요.
